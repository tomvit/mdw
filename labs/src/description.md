k8shell is built on top of a Kubernetes cluster that dynamically provisions user workspaces based on specific requirements, including:

* Pre-installed software in the workspace provided as a container image
* Size specifications (CPU, memory)
* Persistent volume needs for local data storage
* Security such as sudo access
